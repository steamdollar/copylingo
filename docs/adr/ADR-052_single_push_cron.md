# ADR-052: 사용자별 세션 발송은 단일 30분 cron으로 구동한다

- 날짜: 2026-09-26
- 상태: 승인됨

## 배경

ADR-048 이후 네 세션 슬롯의 발송 시각과 시간대는 사용자별 DB 값이다. 그런데 서버 설정에는 과거 전역 시각별 발송 cron과 동적 푸시 cron이 함께 남아 있어, `config.yaml` 없이 실행하면 옛 발송 경로가 다시 활성화될 수 있었다.

## 결정

- 서버는 `*/30 * * * *` cron 작업 하나로 사용자별 발송 조회를 시작한다. 30분 간격은 사용자 설정 UI가 지원하는 최소 시간 단위와 일치한다.
- 전역 오전·오후 Study 및 오전·저녁 Quiz 발송 cron 설정과 레거시 등록 경로를 제거한다. 새 사용자의 네 슬롯 기본 시각은 기존 DB 기본값을 따른다.
- 매일 03:00 자동 콘텐츠 수집 cron 등록도 제거한다. 콘텐츠 수집 파이프라인과 실행 코드는 향후 필요할 때 다시 연결할 수 있도록 유지한다.

## 결과

서버가 등록하는 cron 작업은 사용자별 발송 조회 하나다. 서버가 실행 중일 때 DB 시각에 맞는 사용자를 찾고, 각 슬롯의 중복 발송 방지는 기존 Redis 락을 따른다. 자동 콘텐츠 수집은 중단되지만 저장된 콘텐츠와 수집 코드는 유지된다. Tip·Audio 보충은 현재 30분 발송 조회의 부수 작업으로 남으며, 이를 분리할 때 새 cron을 추가하지 않는 방식을 별도로 결정한다.
