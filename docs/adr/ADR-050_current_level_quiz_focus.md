# ADR-050: Quiz는 현재 레벨과 최근 Study 자료를 우선 편성한다

- 날짜: 2026-09-19
- 상태: 승인됨

## 배경

9월 14일 이후 N4 사용자의 Study는 N4 138/191개(72%)인 반면, 정규 Quiz는 N4 50/174문항(29%), 추가 복습은 12/210문항(6%)이었다. 학습한 N4 자료에 연결된 미출제 문법 170문항과 독해 24문항이 남아 있어 공급 부족보다 편성 우선순위의 문제였다.

ADR-046의 인접 레벨 범위에 서로 다른 규모의 재고를 섞은 뒤 기존 학습 여부·난이도·due 순으로 고르면서 N5 재고가 유리해졌다. 사용자는 N4를 충분히 익힌 뒤 N3로 전환하기 위해 현재 레벨 중심 편성과 최근 Study의 후속 Quiz를 승인했다.

## 결정

- 정규 아침 17문항 중 최소 14문항, 저녁 12문항 중 최소 10문항을 현재 레벨로 확보한다. 80%를 올림한 초기 운영값이며 N4에 하드코딩하지 않는다.
- 현재 레벨의 신규·due 후보를 먼저 편성하고, 남은 기본 자리는 하위 레벨 due 복습으로 채운다. 현재 레벨 후보가 부족할 때만 기존 인접 레벨 범위로 보충해 세션 수량을 유지한다. 자동 레벨 변경은 추가하지 않는다.
- 현재 레벨 청해·독해는 적합한 후보가 있으면 정규 세션마다 각 1문항을 확보한다. 신규 후보가 없으면 해당 유형의 due 후보도 사용할 수 있다. 음성 준비·독해 자료 선행 학습 조건은 유지한다.
- 기존 신규 어휘 예약을 가능한 범위에서 유지한다. 독해 최대 1문항·한자 recall 최대 3문항·Question ID 중복 방지는 그대로 적용한다.
- 신규 문제는 학습한 자료를 우선하고, 자료별 미출제 문항을 한 번씩 분산하면서 최근 Study 자료를 먼저 고른다. 현재 세션에 이미 선정된 자료도 분산 순위에 반영해 같은 자료의 변형 문제 집중을 완화한다.
- 추가 복습은 현재 레벨 due를 우선한 뒤 기존 인접 레벨 due로 보충한다. 신규 문제를 섞거나 미래 복습을 당기지 않는다. 정규 세션의 80% 비율을 due-only 복습에 강제하지 않는다.
- Study 정책과 기존 세션·SRS 이력은 유지한다. 향후 현재 레벨이 N3로 바뀌면 같은 정책이 N3에 적용된다.

## 구현 경계와 절충

- 서비스는 제한된 수량의 후보만 조회해 현재 레벨 편성과 부족분 보충을 조합한다. 사용자별 전체 문제 재고를 앱으로 읽어들이지 않는다.
- 청해·독해 due는 유형별로 1개씩 별도 조회하고, 일반 due 조회는 독해·한자 recall 상한을 LIMIT보다 먼저 적용한다. 특정 유형의 복습 적체가 다른 유형의 후보를 가리지 않도록 한다.
- 현재 레벨 신규 후보가 부족하면 일반 복습 배분량을 넘어 현재 레벨 due로 목표 비중을 확보한다. 복습 기한 자체는 변경하지 않는다.
- repository SQL에서 신규 자료 분산·최근 Study 순서와 due 레벨 우선순위를 적용한다. 새 schema·사용자별 설정 UI·학습 이력 초기화는 필요 없다.
- N5 due 처리는 늦어질 수 있다. 현재 레벨의 학습과 확인 문제 연결을 우선하며, 첫 풀이 정답률·소요 시간·레벨별 실제 편성을 후속 조정 근거로 삼는다.
- 80%는 후보가 충분할 때의 최소 목표다. 해당 레벨의 자료·음성·미출제·due 후보가 부족하면 인접 레벨 비중이 늘거나 전체 세션이 짧아질 수 있다.

## 검증 기준

- N5 재고가 많아도 정규 세션에서 현재 레벨의 목표 수량을 확보하고, current level이 N3여도 동일하게 동작한다.
- 현재 레벨 청해·독해 예약, 신규 어휘 예약, 독해·한자 recall cap, 중복 방지를 함께 검증한다.
- 후보 부족 fallback과 due-only 추가 복습을 검증한다.
- 실제 PostgreSQL 임시 테이블로 최근 Study·자료별 분산·미래 복습 제외·current-first due 정렬을 확인한다.
