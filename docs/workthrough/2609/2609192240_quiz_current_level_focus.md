# Quiz 현재 레벨·최근 Study 자료 우선 편성

## 배경과 승인 범위

- 9월 14일 이후 Study의 N4 비중은 138/191개(72%)였지만 정규 Quiz는 50/174문항(29%), 추가 복습은 12/210문항(6%)이었다.
- 사용자는 N4 중심 정규 Quiz, 최근 Study의 후속 문제, 독해·청해 예약, 현재 레벨 우선 추가 복습을 승인했다.
- [ADR-050](../../adr/ADR-050_current_level_quiz_focus.md)에 편성 목표와 N5 복습이 지연될 수 있는 절충을 기록했다.

## 변경 내용

- 정규 Quiz는 현재 레벨 최소 80%(아침 14/17·저녁 10/12)를 먼저 확보한다. 후보가 부족할 때만 기존 인접 레벨 범위로 보충한다.
- 현재 레벨 독해·청해는 신규 또는 due 후보로 각 1문항을 예약한다. 독해 최대 1·한자 recall 최대 3 및 질문 중복 방지 조건은 유지한다.
- 신규 질문 SQL은 학습 자료별 문항을 분산하고 최근 Study 자료를 우선한다. 현재 세션에서 이미 선정된 자료도 분산 순위에 반영한다.
- 추가 복습 SQL은 현재 레벨 due를 먼저 고른다. 미래 복습이나 신규 문제를 추가 복습에 섞지 않는다.
- 기존 Study 정책과 기존 세션·사용자 SRS 이력은 변경하지 않는다.

## 담당과 변경 경계

- 실행 보조 에이전트: `internal/service/session_builder.go`와 편성 행동 테스트의 초기 구현.
- Primary: 편성 로직 최종 통합과 경계 사례 보완, `internal/repository/question_repo.go`와 SQL 통합 테스트, `internal/service/srs.go`와 repository 호출 계약 테스트, bot·scheduler 테스트 mock의 계약 정렬, ADR·STATUS·최종 검증.
- 스키마 변경·학습 이력 초기화·사용자에게 테스트 세션 발송은 수행하지 않는다.

## 검증

- PostgreSQL 임시 테이블을 사용하는 `TestQuestionSelectionPostgres` 통과: 최근 Study 순서, 같은 자료의 변형 문제 분산, 기선정 자료 반영, 청해 음성·독해 선행 학습 조건, 신규·due 한자 recall 제한, current-level due 우선, 사용자·레벨·미래 복습 제외. 많은 어휘 due 뒤의 청해·독해 조회와 LIMIT 이전 독해 상한도 검증했다.
- 서비스 회귀 테스트 통과: 아침·저녁 현재 레벨 최소 비중, 현재 레벨 due만 충분한 경우, 현재 레벨 문법을 인접 레벨 신규 어휘보다 먼저 선정, 독해 상한으로 인한 잘못된 재고 부족 판단 방지, N3 사용자에게도 동일 정책 적용, 추가 복습의 due-only 동작.
- `COPYLINGO_TEST_DATABASE_URL`을 설정한 `make test` 전체 통과(테스트가 있는 16개 패키지). SQL 통합 테스트는 임시 테이블과 rollback 트랜잭션으로 실행했다. 스케줄러 편성 테스트의 사용자·문제 레벨 누락은 실제 계약에 맞게 보완했다.
- `make restart-app` 완료. 2026-09-19 23:08 KST `http://localhost:8080/health`에서 `status: healthy` 확인.
- 기존 세션은 그대로 두며, 재시작 이후 새로 생성하는 Quiz부터 적용된다. 실제 사용자 세션 생성·테스트 메시지 발송은 하지 않았다.
