## 단어 정리 (2,140 → 1,766)

1. 기존 N4/N5 단어와 표기가 같은 312개, 가나 전용인데 가나가 같은 5개, 접사 2개 제거 → 1,821개
2. sonnet이 뜻(`meaning_ko`)·품사·가나 표기 여부·빈도(1~3)를 달면서 문제 항목을 표시했고, 그중 41개를 제거했다: 단독으로 거의 안 쓰는 한자(意, 学, 生, 不 등), 이체자(河), 드문 읽기(文字=もんじ, 反る=かえる), 뜻·읽기 불일치(棟, 素)
3. 송り가나·표기 18개 수정(押える→押さえる, 交ぜる→混ぜる, 湧く→沸く 등)
4. 가나로 쓰는 단어가 N4/N5나 다른 N3 항목과 같아지는 14개 제거(有る→ある, 只/唯→ただ) → 1,766개

### `difficulty`는 빈도

N3 단어 material의 `difficulty` = 빈도 + 1 (흔함 2: 943개, 보통 3: 760개, 드묾 4: 63개). Study 신규 선택이 같은 레벨 순위 안에서 `difficulty` 오름차순이라, 레벨을 N3로 바꾸면 흔한 단어부터 나온다. N4/N5 단어는 전부 2다.

## 문항 생성

N4와 같은 혼합 방식(사용자 결정).

| 대상 | 방식 | 유형 | 수 |
|---|---|---|---|
| 한자로 쓰는 단어 1,503 | 스크립트 | `vocab_kanji_reading` 743 / `vocab_orthography` 760 (번호 홀짝으로 교대, 같은 한자에 읽기가 여럿이면 표기) | 1,503 |
| 가나로 쓰는 단어 263 | sonnet 작성 → opus 전수 검수 | `vocab_context` 132 / `vocab_usage` 131 | 263 |
| 문법 98 | sonnet 작성 → opus 전수 검수 | `grammar_form` / `sentence_composition` / `grammar_text` 각 98 | 294 |

- 표기 문항 오답: 같은 발음의 다른 한자 단어 > 같은 한자를 쓰는 단어 > 같은 품사·글자 수 순으로 고른다. 지문은 가나와 한국어 뜻만 보여주므로 **뜻이 겹치는 동음어(磁器/磁気=자기)는 오답에서 뺀다**. 188문항에 동음어 오답이 들어갔다.
- 동음·동의 쌍 動揺/童謡(둘 다 '동요')는 지문이 같아져서 뜻을 '동요 (마음의 흔들림)', '동요 (어린이 노래)'로 나눴다.
- 단어 문항과 같은 내용이 되지 않도록, 단어 자료에 이미 있는 부사·접속사(つまり, ところが, むしろ 등 20개)는 문법에서 뺐다. 동사 복합형은 `ます形+切る`처럼 이름을 바꿔 남겼다.
- LLM 작성 문항의 해설은 9월 해설 개편 수준(정답 해석 + 오답별 이유)으로 맞췄다.

## 지금 학습 흐름에 미치는 영향

- 현재 레벨 N4의 학습 범위는 N5·N4·N3이고, 신규는 현재 레벨을 먼저 낸다(ADR-047). 그래서 N3 **단어**는 N4 신규 단어(약 590개 남음)가 끝나야 나온다.
- N3 **문법**은 곧 나온다. N4 문법은 2개, N5 문법은 0개만 남아서 Study의 신규 문법 자리(세션당 1개)가 N3 문법으로 채워진다.
- 레벨을 N3로 바꾸면 범위가 N4·N3·N2가 되어 N3가 우선되고 N5는 빠진다.

## 남은 확인 사항

- 원어민 검수는 받지 않았다.
- 독해·청해는 범위 밖이다(청해는 TTS 음성 생성 필요).
- 단어 리스트의 영어 뜻이 다른 읽기 것으로 붙은 항목(盛り=さかり, 末=すえ 등)은 읽기 기준으로 뜻을 달았다.
- 생성 스크립트는 일회성이라 저장소에 넣지 않았다. 이후 수정은 `n3.json`을 직접 고친다.
