# Go 1.27.0 Upgrade

## 배경과 결정

- Go 1.27.0이 2026-08-19 정식 release됨에 따라 project minimum toolchain과 container builder를 함께 upgrade했다.
- ADR-044에 따라 dependency upgrade·신규 API 도입은 분리하고 exact patch version을 pin했다.

## 변경 내용

- `go.mod`: `go 1.25.5` → `go 1.27.0`.
- `Dockerfile`: builder image `golang:1.25-alpine` → `golang:1.27.0-alpine`.
- Clean Docker build를 막던 stale `COPY --from=builder /app/data ./data`를 제거했다. Catalog JSON은 `go:embed`로 binary에 포함되고 top-level `data/`는 존재하지 않는다.
- `go mod tidy`는 `go.sum`과 dependency graph를 변경하지 않았다.

## 검증

- `GOTOOLCHAIN=go1.27.0 go mod tidy` — PASS
- `make test` — PASS (Go 1.27.0)
- `make build` — PASS
- `docker build -t copylingo:go1.27-smoke .` — PASS
- container image binary `go version -m` — `go1.27.0`
- `make restart-app` — PASS (`http://localhost:8080/health` ready)
- `git diff --check` — PASS
